# π0.5 LoRA 微调 on LIBERO：短板定位与定向蒸馏

在 LIBERO-Spatial 上用 LoRA 微调 π0.5（openpi），和基座模型、官方全量微调对比；定位 LoRA 模型最弱的任务，用“人类演示 + 教师策略蒸馏轨迹”定向补强，并测量对其他任务的遗忘。

## 结果一览

| 模型 | 训练 | 抽屉任务（50 个初始状态） | LIBERO-Spatial 整套（每任务 5 次，共 50） |
|---|---|---|---|
| π0.5 base（未微调） | 无 | – | 0% |
| LoRA | 5k 步 × batch 32 | 58%（29/50） | 88%（44/50） |
| LoRA + 抽屉定向微调 | 再训 2k 步，100 条抽屉演示 | **96%（48/50）** | 84%（42/50） |
| 官方 `pi05_libero`（全量微调） | 30k 步 × batch 256 | 96%（48/50） | 92%（46/50） |

抽屉任务指 `pick up the black bowl in the top drawer of the wooden cabinet and place it on the plate`。

## 1. 基线与 LoRA 微调

- 基座：`pi05_base`，LoRA 变体 `gemma_2b_lora`（rank 16）+ `gemma_300m_lora`（rank 32），`ema_decay=None`。
  openpi 的 `freeze_filter` 只冻结 LLM 主干，SigLIP 视觉编码器和投影层仍全量训练。
- 数据：`physical-intelligence/libero`（LIBERO 四个套件合并），π0.5 使用分位数归一化（q01/q99）。
- 训练：A100-80GB，5000 步 × batch 32，约 2.8 s/步、4 小时；GPU 利用率持续 100%（计算瓶颈，不是数据加载瓶颈）。
- 训练量只有官方的约 1/48（16 万 vs 768 万样本）。

在整套 LIBERO-Spatial（每任务前 5 个初始状态）上达到 88%，接近官方的 92%。

## 2. Bad case 分析

LoRA 模型的 6 次失败分布在 4 个任务上，看回放视频后分两类：

| 类型 | 任务 | 现象 |
|---|---|---|
| 抓取失败 | 抽屉里的碗 | 夹爪一侧手指卡在抽屉边缘，夹不住碗 |
| 判定失败 | 柜子上 / 饼干盒上 / 饼干盒旁 | 碗已放进盘子，但偏离盘子中心 |

第二类与 LIBERO 的成功判定有关：`check_ontop` 要求物体接触、高度关系成立，且两者中心的水平距离 < 3cm（`libero/envs/object_states/base_object_states.py`）。放进盘子但偏心超过 3cm 不算成功，最后超时失败。

对抽屉任务单独用全部 50 个初始状态评测：**LoRA 58%，官方 96%**。说明任务本身不难，LoRA 模型在需要避障的精细抓取上训练不足。

## 3. 定向补强：人类演示 + 教师蒸馏

- 数据：抽屉任务的约 50 条人类演示（取自原数据集）+ 50 条官方模型的成功轨迹。
- 防泄漏：蒸馏轨迹用 `env.reset()` 随机摆放采集，不使用评测用的 50 个固定初始状态。
- 训练：从 LoRA 5k 步 checkpoint 继续训 2000 步（batch 32），沿用原 LIBERO 数据集的归一化统计。

结果：抽屉任务 58% → **96%**，追平官方全量微调。

## 4. 遗忘

只用单任务数据训练后，整套 LIBERO-Spatial 从 88% 降到 84%。总数只差 2 个回合，在 50 回合的评测里属于噪声范围；但原来全对的 3 个任务出现了失败：

| 任务 | 补强前 | 补强后 |
|---|---|---|
| 抽屉里的碗 | 有失败 | 5/5 |
| 柜子上的碗 | 有失败 | 5/5 |
| 饼干盒旁边的碗 | 有失败 | 4/5 |
| 饼干盒上的碗 | 有失败 | 3/5 |
| ramekin 旁边的碗 | 5/5 | 4/5 |
| ramekin 上的碗 | 5/5 | 3/5 |
| 盘子旁边的碗 | 5/5 | 3/5 |
| 其余 3 个任务 | 5/5 | 5/5 |

补强前的 6 次失败落在前 4 个任务上，具体每个任务失败几次没有记录（只保留了总数和失败视频）。

下一步可以混入其他任务的演示一起训，看能否在保住抽屉任务的同时避免遗忘。

## 局限

- 整套评测每任务只跑 5 次，总共 50 回合，±4% 级别的差异不显著。
- 训练和评测是同一批任务，只换初始状态，衡量的是任务掌握程度，不是泛化。
- 每组只跑了一个随机种子。

## 复现

- 训练配置：`pi05_libero_lora`、`pi05_libero_lora_drawer`（见 `configs/`）。
- 蒸馏数据采集：`scripts/collect_rollouts.py`；构建数据集：`scripts/build_drawer_dataset.py`。
- 评测：openpi `examples/libero/main.py`，加了 `--args.task-filter` 和按回合命名视频（见 `scripts/patch_main.py`）。
- 环境：openpi `c23745b5`，评测在 L4（24GB），训练在 A100-80GB。
